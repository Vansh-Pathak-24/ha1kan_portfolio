# ha1kan

Brutalist black and white portfolio built with React, Vite, Tailwind CSS 4, GSAP and Lenis.

## Scripts

- `npm run dev` start the dev server
- `npm run build` production build
- `npm run lint` run ESLint
- `npm run preview` preview the production build

## Content

All copy, links and project data live in `src/lib/site.js`.
